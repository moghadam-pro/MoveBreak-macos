MoveBreak for macOS

A calm, offline reminder to move and rest your eyes. Requires macOS 14 or later. Supports Apple Silicon and Intel.

Install

  1. Drag MoveBreak.app onto the Applications shortcut in this window.
  2. Open Applications and double-click MoveBreak.
  3. Choose your language in Settings. Notifications and launch at login are optional.

No Terminal, command, setup script, runtime download, or account is needed. Eject the disk image after copying the app.

Beta security status

This beta is locally ad-hoc signed and has not been notarized by Apple. A downloaded copy may be blocked by macOS Gatekeeper. Seamless downloaded installation requires a Developer ID signed and Apple-notarized release. No installer script changes macOS security settings.

For the operating system's explanation, see Apple: Open apps safely on your Mac. Only install software you trust. The application remains fully bundled; no shell is required.

Permissions

MoveBreak works without notification permission. To receive system notifications, use Settings → Enable system notifications. Use the test notification button to check delivery. Launch at login is optional and is controlled by macOS Login Items.

MoveBreak does not require Accessibility, Input Monitoring, Screen Recording, camera, microphone, or Full Disk Access permissions.

نصب

فایل MoveBreak.app را روی میانبر Applications بکشید. سپس برنامه را از پوشهٔ Applications باز کنید. هیچ دستور Terminal یا راه‌اندازی جداگانه‌ای لازم نیست. زبان فارسی را از تنظیمات انتخاب کنید. این نسخهٔ بتا هنوز notarize نشده و ممکن است نسخهٔ دانلودشده توسط سیستم امنیتی مک مسدود شود.
